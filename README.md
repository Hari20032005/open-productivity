# FreeFlow — Reclaim Your Mind. Own Your Time.

> The first app that combines genuine distraction blocking, addiction recovery, task management, and an AI coach in one product.

## Why FreeFlow Exists

The $12B+ productivity market has a fundamental design flaw: it splits blocking from recovery. Users cobble together 3–5 separate apps (Cold Turkey, AppBlock, Forest, Todoist, Covenant Eyes) and still fail because each solves only one dimension of a deeply interconnected problem.

**The neuroscience is clear:** the same dopamine pathways that social media and pornography exploit are the ones that productive habits need to recruit. FreeFlow is the first app to understand this dual nature — blocking cheap dopamine while engineering healthy dopamine loops.

## Key Features

### 🛡️ Shield Mode (Blocking + Friction)
- **Allowlist-first architecture** — define productive apps, block everything else
- **One Sec-style friction** — proven 57% reduction (PNAS peer-reviewed study)
- **Partner-held credentials** for truly unbypassable strict mode
- **Context-aware profiles**: Deep Work, Admin, Creative, Evening, Recovery
- **Emergency 24h lock** for high-urge moments
- **DNS-level porn filtering**

### 🔥 Recovery Mode (Streaks + Journal + Community)
- **Visual streak tracking** with 90-day reboot framework
- **Non-judgmental relapse logging** — no shame, just data
- **Science-backed milestone celebrations** (Day 7, 14, 30, 60, 90, 180, 365)
- **HALT urge framework** (Hungry, Angry, Lonely, Tired)
- **Daily mood + urge journal** with pattern tracking
- **Community feed** with accountability challenges

### ⚡ Build Mode (Productivity + Habits)
- **GTD Inbox** — instant capture for all "open loops"
- **1-3-5 daily rule** — 1 major + 3 medium + 5 small tasks
- **Eisenhower Matrix** task prioritization
- **Pomodoro timer** with automatic app blocking during sessions
- **Done List** — micro-dopamine reward for every completed task
- **James Clear's 4-law habit framework** (Make it Obvious, Attractive, Easy, Satisfying)

### 🤖 AI Recovery Coach
- Powered by Claude Sonnet (claude-sonnet-4-6)
- CBT + ACT-based conversational support
- HALT-aware urge intervention
- Daily personalized check-ins
- Identity transformation framing: "I am someone who focuses deeply"

## The Five Strategic Imperatives (from research)

1. **Build allowlist-first blocking** — hardest technical challenge, deepest moat
2. **Friction before blocking** — One Sec model is more sustainable than hard walls
3. **Recruit dopamine, don't fight it** — every productive behavior triggers a reward
4. **Accountability: human and private** — filtered reports, not invasive screenshots
5. **Design for identity transformation** — become someone who naturally focuses
